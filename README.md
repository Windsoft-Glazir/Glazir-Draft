# Glazir Draft

Glazir Draft는 브라우저에서 2D 도면을 열고 편집하며 3D 모델링과 팀 협업을 지원하는 Windsoft 도면 작업 도구입니다. Community는 도면 열기·편집과 로컬 저장을 지원합니다.
